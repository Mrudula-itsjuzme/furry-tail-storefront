# Furry Tail

A multi-page front-end prototype for a premium pet-care brand, built around product storytelling, calm visual hierarchy, and a polished direct-to-consumer shopping experience.

> **Design study / front-end prototype** — focused on brand-led commerce, responsive layouts, interaction details, and translating a product identity into a complete web experience.

## What this project explores

Most storefronts are built around dense grids, discounts, and conversion-first UI. This project explores a different direction: a quieter, editorial e-commerce experience for a natural pet-care brand.

The site treats each product as part of a larger care ritual rather than as an isolated card in a catalogue. The result is a multi-page experience spanning discovery, product education, brand context, pet-specific navigation, and supporting information.

## Experience

The prototype includes:

- dedicated product pages for shampoos, sprays, paw care, fragrance, and related pet-care products
- separate browsing paths for dogs and cats
- product-category discovery and ritual-oriented navigation
- About, FAQ, contact, and supporting brand pages
- responsive layouts for desktop and mobile
- custom hover states, transitions, typography, and spacing system
- image and video-led product presentation
- reusable shared styling across a static multi-page architecture

## Design direction

The visual system uses restrained typography, soft natural tones, generous whitespace, and slower interaction motion to make the storefront feel closer to an editorial brand site than a conventional marketplace.

Key ideas:

- **calm over clutter** — hierarchy before density
- **product storytelling** — context and use before hard selling
- **consistent visual language** — shared spacing, type, interaction, and surfaces across pages
- **responsive by design** — category layouts and navigation adapt for smaller screens
- **brand as interface** — visual identity is carried through interaction, not just logos and colors

## Built with

`HTML` `CSS` `JavaScript` `Responsive Design` `UI/UX` `E-commerce Prototyping`

The project intentionally uses a lightweight static stack so the focus stays on the interface system, content architecture, and visual execution rather than framework complexity.

## Structure

The repository contains the storefront home page, category and product pages, informational pages, shared styling, and supporting product media.

Examples include:

- `index.html` — storefront landing page
- `for-dogs.html` / `for-cats.html` — pet-specific discovery
- individual product-detail pages
- `about.html`, `faq.html`, `contact.html`
- `shared.css` — common visual and layout system

## Status

Prototype / design exploration. This is not presented as a production commerce backend or live transactional store.
